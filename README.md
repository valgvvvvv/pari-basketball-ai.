# PARI Basketball AI — MVP 0.1

Новый самостоятельный проект для анализа баскетбольных матчей и тоталов матча/четвертей.

## Что уже реализовано
- Адаптивный русскоязычный интерфейс.
- Ручной ввод LIVE-состояния матча и линии PARI.
- Расчёт темпа, проекции итогового тотала и остаточных очков.
- Пуассоновская вероятность ТБ/ТМ.
- Монте-Карло симуляция (настраиваемое число прогонов).
- Учет формата 4×10 / 4×12, текущей четверти, времени, счета, фолов и корректировки концовки.
- Отдельный анализ четверти.
- Оценка качества входных данных и предупреждения.
- История анализов в локальном браузере.
- Архитектура адаптера для подключения официального/разрешённого PARI feed.

## Важно о PARI LIVE
Публично подтверждённая страница баскетбольного LIVE: https://pari.ru/live/basketball
В проекте намеренно НЕ зашит выдуманный API PARI. Для автоматического получения LIVE-данных нужен подтверждённый официальный/лицензированный feed, документированный endpoint или разрешённый способ интеграции. Не передавайте приложению логин/пароль от аккаунта PARI.
Пока источник не подключён, интерфейс явно показывает режим «ручной ввод / демонстрация», а не выдаёт старые или тестовые данные за актуальные.

## Быстрый запуск
Нужен Python 3.10+.

```bash
cd pari_basketball_ai
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --reload
```
Откройте http://127.0.0.1:8000

## Подключение поставщика данных
1. Получить разрешённый feed и документацию от поставщика.
2. Реализовать `providers/pari_provider.py` по контракту в `providers/base.py`.
3. Настроить переменные окружения, не хранить ключи в браузере.
4. Добавить мониторинг задержки, полноты и согласованности снимков.
5. Прогнать интеграционные тесты на реальных матчах.
